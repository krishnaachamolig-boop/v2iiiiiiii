# Android native project

This folder is intentionally NOT a full generated Android Studio project —
that project is generated by the Capacitor CLI itself (`npx cap add android`),
which needs the Android SDK/Gradle toolchain installed locally. Generating it
requires running actual Gradle/SDK tooling, which this build environment does
not have (no network, no Android SDK installed).

## To generate it yourself

```bash
npm install
npm run build
npx cap add android
npx cap sync android
```

This creates `android/app/src/main/AndroidManifest.xml` and the full Gradle
project. After it's generated, apply the permissions below.

## Required permissions (add to AndroidManifest.xml)

Only request what the app actually uses — do not add anything beyond this list:

```xml
<!-- Microphone: required for voice input (recording + browser/cloud STT) -->
<uses-permission android:name="android.permission.RECORD_AUDIO" />

<!-- Internet: required for Supabase, AI provider, voice providers, search -->
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />

<!-- Notifications (Android 13+ requires runtime request, handled by
     @capacitor/local-notifications automatically once this is declared) -->
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />

<!-- Exact alarm scheduling for reminders (Android 12+). Without this,
     reminders may fire late under Doze — see the caveat below. -->
<uses-permission android:name="android.permission.SCHEDULE_EXACT_ALARM" />

<!-- File picker / uploads via the OS document picker (no broad storage
     permission needed — Capacitor Filesystem + the system picker use
     scoped storage, which requires no dangerous permission on API 29+) -->
<uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
```

## Known, unavoidable Android limitations (stated honestly, not glossed over)

1. **Wake-word / always-on listening is NOT implemented.** True background
   wake-word detection requires a persistent foreground service plus a
   native on-device wake-word engine (e.g. Porcupine) — out of scope for
   this build. Voice input here is tap-to-talk / hold-to-talk only, which
   works reliably; the `VoiceCloneProvider`/activation architecture leaves
   a slot for wake-word to be added later without changing the rest of the app.
2. **Reminder delivery is not 100% guaranteed in the background** on OEM
   Android skins (Xiaomi/MIUI, Oppo/ColorOS, Vivo) that aggressively kill
   background processes regardless of standard Android APIs. The app
   requests `SCHEDULE_EXACT_ALARM` and uses `@capacitor/local-notifications`
   correctly, but cannot override OEM battery-optimization behavior. Surface
   this to users in Settings → Notifications with a "disable battery
   optimization for this app" instruction.
3. **Computer-control / "click, type, navigate" actions** are implemented
   only for in-app/browser-safe contexts (see `src/tools/registry.ts` — no
   OS-level input injection is implemented, since that requires Accessibility
   Service permissions with significant review/security implications). This
   is intentionally left as an architectural extension point, not faked.

## App icon / splash

Standard Capacitor asset generation applies once the project is generated:

```bash
npm install -D @capacitor/assets
npx capacitor-assets generate
```

Place a 1024x1024 `icon.png` and `splash.png` in `resources/` first.
